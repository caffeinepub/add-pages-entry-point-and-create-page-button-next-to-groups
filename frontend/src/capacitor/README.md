# Capacitor Android Build Guide

This directory contains Capacitor-specific runtime utilities and configuration for building CivWorld as an Android app.

## Prerequisites

Before building the Android app, ensure you have:

1. **Node.js and npm/pnpm** installed
2. **Android Studio** installed with:
   - Android SDK (API level 33 or higher recommended)
   - Android SDK Build-Tools
   - Android SDK Platform-Tools
   - Android Emulator (optional, for testing)
3. **Java Development Kit (JDK)** 17 or higher
4. **Capacitor CLI** installed globally: `npm install -g @capacitor/cli`
